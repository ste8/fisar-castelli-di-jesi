# FISAR Castelli di Jesi — Repository di progetto

Repository di progettazione e sviluppo del nuovo sito web della Delegazione FISAR Castelli di Jesi.

Il repository contiene:

- documentazione fondativa;
- brand book;
- architettura informativa;
- specifiche di pagina;
- specifiche plugin WordPress;
- specifiche tema WordPress;
- mockup approvati;
- roadmap di sviluppo;
- cartelle future per `plugin/`, `theme/` e `docker/`.

## Stato

Progetto in fase di progettazione.

## Principio guida

Il sito non è solo un catalogo di eventi e corsi: è uno strumento per raccontare e far crescere la comunità della Delegazione FISAR Castelli di Jesi.

Payoff guida:

> Il vino come punto di partenza, le persone al centro.
