# Tema WordPress

Il tema installabile è `fisar-cdj/`.

Include homepage, archivi e singoli Eventi/Corsi, elenco e singoli articoli del Blog, pagine editoriali, header/footer, componenti, design token, menu mobile e stili responsive/accessibili.

Il tema dipende da `fisar-cdj-core` per dati e logiche di dominio. Non include framework, page builder, font remoti o librerie JavaScript esterne.

Riferimenti: [Architettura](../docs/architecture.md), [Sistema visivo](../docs/design-system.md) e [Guida editoriale](../docs/editorial-guide.md).
