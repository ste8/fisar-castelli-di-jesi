# Font del tema

Il tema usa **Poppins**, pesi `400`, `500`, `600`, `700`, per corpo, interfaccia, titoli, payoff e citazioni. I quattro WOFF2 statici sono ospitati localmente e limitati al subset latino; solo il Regular è precaricato. Il preset storico `fisar-heading` è un alias Poppins per i blocchi già salvati.

Poppins è distribuito con licenza SIL Open Font License 1.1, riportata in `poppins/OFL.txt`. Font originali: <https://github.com/google/fonts/tree/main/ofl/poppins>.

I WOFF2 Poppins provengono dal subset latino distribuito da Google Fonts (versione CSS `v24`). Non sono caricati servizi Google o Adobe durante la navigazione. I precedenti asset Inter non sono utilizzati.
