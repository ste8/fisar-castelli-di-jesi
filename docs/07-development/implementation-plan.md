# Implementation Plan
## Obiettivo
Passare subito a una V1 funzionante e affinare sul sito reale.

## Ordine
1. Docker + WordPress.
2. Skeleton plugin e tema.
3. CPT Eventi e Corsi + meta fields.
4. Import calendario.
5. Header/footer + design tokens.
6. Homepage.
7. Archive/single Eventi.
8. Archive/single Corsi.
9. News e pagine editoriali.
10. Carta dei Valori, Chi siamo, Contatti, Unisciti a noi.
11. Test responsive/accessibilità/performance.

## Istruzione consigliata per Codex
“Implementa la V1 del sito WordPress seguendo tutte le specifiche presenti in `docs/`. Mantieni separate logica (`plugin/`) e presentazione (`theme/`). Usa Docker per l'ambiente di sviluppo. Accessibilità e responsive sono requisiti della prima implementazione. Non aggiungere funzionalità non richieste; se una specifica è ambigua, scegli la soluzione più semplice e documenta l'assunzione.”
