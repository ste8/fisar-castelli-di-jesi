# Homepage Concept 01

## Stato

Approvato come prima base progettuale.

## File

```txt
homepage-concept-01.png
```

## Decisioni principali

- Top bar bordeaux.
- Payoff nella top bar.
- Social a destra: Canale WhatsApp, Instagram, Facebook.
- Logo a sinistra.
- Menu senza "Home".
- News nel menu principale.
- CTA "Unisciti a noi".
- Hero fotografico caldo.
- Le Quattro Porte:
  - Eventi
  - Corsi
  - Unisciti a noi
  - Carta dei Valori
- Prossimi eventi prima dei corsi.
- Sezione News in homepage.
- Sezione dedicata ai valori.
- Footer con newsletter e social.

## Note

Il concept è un riferimento di direzione visiva e struttura, non un layout pixel-perfect.

## Da rifinire

- Logo orizzontale definitivo.
- Fotografia hero definitiva, preferibilmente reale della Delegazione.
- Iconografia coerente.
- Versione mobile dettagliata.
- Stati hover/focus.
