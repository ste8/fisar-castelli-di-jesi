# Design System

## Elementi principali

- Top bar bordeaux.
- Header bianco.
- CTA "Unisciti a noi".
- Titoli grandi con sottolineatura breve.
- Card evento con locandina protagonista.
- Sezione "Come seguirci" con canali e newsletter.
- Footer con newsletter e social.

## Accessibilità

- CTA con testo esplicito.
- Focus visibile.
- Contrasti verificati.
- Menu navigabile da tastiera.
