# Theme Spec

Il tema contiene la presentazione del sito.

## Responsabilità

- Header
- Footer
- Homepage
- Archivio Eventi
- Pagina Evento
- Archivio Corsi
- Pagina Corso
- News
- Carta dei Valori
- Responsive
- Accessibilità

## Direzione visiva

Eleganza calda:

- sfondo bianco;
- top bar bordeaux;
- oro FISAR;
- fotografie calde e conviviali;
- locandine evento protagoniste.
