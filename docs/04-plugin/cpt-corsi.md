# CPT Corsi

## Scopo

Rappresentare corsi FISAR di 1°, 2° e 3° livello.

## Campi principali

- Titolo
- Descrizione
- Immagine in evidenza
- Direttore del Corso
- Livello
- Data inizio
- Data fine
- Luogo
- Calendario lezioni
- Iscrizioni
- Quota di partecipazione
- Tesseramento FISAR
- Cosa comprende il corso

## Corsi attivi

```txt
data_fine >= oggi
```

## Corsi conclusi

```txt
data_fine < oggi
```
